# Modern Software Development Resources

## Knowledge

- [Book: *Accelerate: The Science of Lean Software and DevOps* by Nicole Forsgren, Jez Humble, and Gene Kim](https://itrevolution.com/product/accelerate/)
  Rigorous empirical research defining what makes software teams high-performing (DORA metrics: deployment frequency, lead time, change fail rate, MTTR). Use for: understanding engineering velocity, delivery benchmarks, and release culture.
- [Guide: *The Twelve-Factor App* by Adam Wiggins](https://12factor.net/)
  Foundational principles for cloud-native web apps (declarative configuration, backing services, stateless processes, concurrency, dev/prod parity). Use for: understanding modern deployment architecture and environment management.
- [Book: *Continuous Delivery: Reliable Software Releases through Build, Test, and Deployment Automation* by Jez Humble and David Farley](https://continuousdelivery.com/)
  The foundational text on automated build and deployment pipelines. Use for: pipeline design, deployment strategies, and release automation.
- [Documentation: GitHub Actions Documentation](https://docs.github.com/en/actions)
  Industry standard workflow automation and CI/CD platform. Use for: understanding automated testing, build triggers, and release automation in real repositories.
- [Book: *Designing Data-Intensive Applications* by Martin Kleppmann](https://dataintensive.net/)
  The definitive guide to modern data architectures, distributed systems, and reliability. Use for: understanding databases, caching, message queues, and API design.

## Wisdom (Communities)

- [r/ExperiencedDevs](https://reddit.com/r/ExperiencedDevs)
  High-signal community where senior and staff engineers discuss system design, technical leadership, SDLC friction, and management collaboration. Use for: understanding what engineers experience on the ground.
- [Hacker News](https://news.ycombinator.com)
  High-volume community of founders, engineers, and tech leaders debating modern tooling, architecture choices, and real-world post-mortems. Use for: industry shifts and real-world system failure retrospectives.
- [r/ProductManagement](https://reddit.com/r/ProductManagement)
  Peer forum of product managers sharing experiences scoping technical work, working with engineering leads, and managing technical debt. Use for: cross-functional communication patterns.
