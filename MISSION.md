# Mission: Modern Software Development

## Why
Collaborate effectively with and lead software engineering teams as a founder, PM, or leader by mastering the end-to-end software delivery lifecycle, evaluating technical trade-offs with confidence, and understanding what engineers actually do at each stage.

## Success looks like
- Confidently trace a feature's journey across every stage: discovery/spec, system architecture, version control & branching, automated testing & CI, containerization, cloud deployment, and production observability.
- Fluently communicate with engineers using accurate industry terminology and understand where technical debt, velocity bottlenecks, and release risks occur.
- Inspect and understand a working modern full-stack web project (TypeScript, React/Node, GitHub Actions, Docker, cloud hosting) and its delivery pipeline.
- Evaluate engineering proposals, pull request workflows, and deployment strategies with an informed mental model of trade-offs.

## Constraints
- Beginner coding background: emphasize conceptual clarity, mental models, and practical workflow mechanics over low-level syntax drills.
- Anchor examples around a modern full-stack web stack (TypeScript/React, GitHub Actions, Docker, cloud deployment).

## Out of scope
- Low-level systems programming (e.g. C/C++, manual memory management).
- Advanced algorithmic theory / competitive programming.
