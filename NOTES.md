# Notes: Modern Software Development

## Topic
End-to-end modern software development lifecycle (SDLC) for tech leaders, founders, and product managers.

## User Persona & Goals
- **Role / Objective**: Lead, manage, or collaborate effectively with engineering teams as a PM, founder, or technical leader.
- **Experience Level**: Beginner to coding — prefers clear high-level architectural models, visual flowcharts, and practical comprehension over low-level code trivia.
- **Anchor Stack**: Modern full-stack web stack (TypeScript/Node/React, Git/GitHub, GitHub Actions, Docker, Cloud hosting like Vercel/AWS).

## Pedagogical Strategy
- Structure each lesson with a clear mental model, an interactive comprehension check (retrieval practice), and real-world leadership scenarios ("What would you ask your engineer here?").
- Produce clean, beautiful, self-contained HTML lessons referencing `assets/style.css`.
- Maintain reference sheets (cheat sheets, lifecycle diagrams, glossaries) that summarize key takeaways for quick lookup.
